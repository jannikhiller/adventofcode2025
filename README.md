🎄🎄🎄 Advent of Code 2025 🎄🎄🎄
==================================

Advent of Code 2025 solutions in Rust.

Practicing algorithms, problem solving, and idiomatic Rust.

Usage
-----
The app expects a `.env` file with the `AOC_SESSION` environment variable set.

To download all available inputs and run the solution for the most recent day, use:
```bash
cargo run
```
For more options, run:
```bash
cargo run -- -h
```
